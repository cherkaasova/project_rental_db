# Аренда торговых площадей — база данных

## Технологии
PostgreSQL, SQL, триггеры, процедуры, оконные функции

## Что сделано
- 8 таблиц с ключами и ограничениями
- JOIN, агрегации, работа с датой и текстом
- Триггер на проверку длительности аренды
- Процедура с курсором для обновления цен
- Каскадное удаление без CASCADE
- Star-схема для необязательных атрибутов
- Аналитика: рейтинг точек по выручке
